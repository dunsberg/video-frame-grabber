# 视频抽帧工具 · Video Frame Grabber

> 从本地视频中**精确截取任意一帧**，导出**原始分辨率无损 PNG**。
>
> Grab any exact frame from a local video and export it as a lossless, full-resolution PNG.

纯网页实现：**零依赖、零安装、不联网、不上传**——下载后双击 `index.html` 即可使用。

## 为什么需要它？

| 方式 | 问题 |
|---|---|
| Windows/Mac 截屏播放器 | 截的是**屏幕像素**：4K 视频在 1080p 屏上必然降质，还可能因硬件加速黑屏 |
| 在线抽帧网站 | 要上传视频，慢，隐私没保障 |
| **本工具** | 浏览器解码出视频**原始每一帧的像素**，canvas 原尺寸导出，无损 |

## 使用方法

### 方式一：直接在线用

打开 [GitHub Pages 在线版](https://dunsberg.github.io/video-frame-grabber/)（视频在本地解码，不会上传）。

### 方式二：下载使用

1. 下载本仓库的 `index.html`
2. 双击用 **Chrome / Edge** 打开
3. 拖入视频 → 播放到大致位置后暂停 → `←`/`→` 逐帧微调 → 点 **导出 PNG**

导出文件名自动带时间码和帧号（如 `video_01-23-456_f083.png`），方便回溯。

## 快捷键

| 按键 | 功能 |
|---|---|
| `空格` | 播放 / 暂停 |
| `←` / `→` | 后退 / 前进 1 帧 |
| `Shift + ←` / `Shift + →` | 后退 / 前进 10 帧 |
| `,` / `.` | 后退 / 前进 1 帧 |

工具会在载入视频时自动探测帧率（也支持手动选择 23.976 / 24 / 25 / 30 / 50 / 60 fps）。

## 前置条件（只有一条，且大概率你已经满足）

**不需要安装任何软件或解码器**——解码由浏览器原生完成。唯一要求是视频编码为浏览器支持的常见格式：

- ✅ **MP4（H.264）**、**WebM（VP9 / AV1）**、大多数 MOV —— 直接用
- ❌ HEVC / H.265、ProRes 等专业编码浏览器可能打不开 → 用 ffmpeg 一行转码：

```bash
ffmpeg -i input.mov -c:v libx264 -crf 18 output.mp4
```

## 命令行替代方案

习惯命令行或需要批量抽帧时，ffmpeg 一条命令同样无损：

```bash
ffmpeg -ss 00:01:23.456 -i input.mp4 -frames:v 1 frame.png
```

（`-ss` 放在 `-i` 前是精确到该时间点的帧。）

## 浏览器支持

| 浏览器 | 状态 |
|---|---|
| Chrome / Edge（桌面版） | ✅ 完整支持 |
| Safari 15.4+ | ✅ 基本支持（个别环境下"复制到剪贴板"不可用，导出功能不受影响） |
