# 视频抽帧 & 剪辑工具 · Video Frame Grabber & Clipper

> 从本地视频中**精确截取任意一帧**（导出原始分辨率无损 PNG），或**截取一段导出为新 MP4**（无损流复制，不重编码）。
>
> Grab any exact frame from a local video as a lossless PNG, or cut a segment into a new MP4 — all in your browser.

纯网页实现：**零安装、不上传**——下载后双击 `index.html` 即可使用（剪辑功能首次使用需联网加载一次引擎，见下文）。

## 为什么需要它？

| 方式 | 问题 |
|---|---|
| Windows/Mac 截屏播放器 | 截的是**屏幕像素**：4K 视频在 1080p 屏上必然降质，还可能因硬件加速黑屏 |
| 在线抽帧网站 | 要上传视频，慢，隐私没保障 |
| **本工具** | 浏览器解码出视频**原始每一帧的像素**，canvas 原尺寸导出，无损 |

## 两个功能

1. **📷 抽帧**：定位到任意一帧（逐帧步进），导出原始分辨率无损 PNG，或复制到剪贴板。文件名自动带时间码和帧号（如 `video_01-23-456_f083.png`）。
2. **✂️ 剪辑**：定位到起点按 `I`，定位到终点按 `O`，点“输出片段”得到一个新的 MP4/WebM——采用**无损流复制**（`-c copy`），不重新编码，画质零损失，速度极快。

## 使用方法

### 方式一：直接在线用

打开 [GitHub Pages 在线版](https://dunsberg.github.io/video-frame-grabber/)（视频在本地解码，不会上传）。

### 方式二：下载使用

1. 下载本仓库的 `index.html`
2. 双击用 **Chrome / Edge** 打开
3. 拖入视频 → 播放到大致位置后暂停 → `←`/`→` 逐帧微调 → 点 **导出 PNG**

导出文件名自动带时间码和帧号（如 `video_01-23-456_f083.png`），方便回溯。

## 快捷键

| 按键 | 功能 |
|---|---|
| `空格` | 播放 / 暂停 |
| `←` / `→` | 后退 / 前进 1 帧 |
| `Shift + ←` / `Shift + →` | 后退 / 前进 10 帧 |
| `,` / `.` | 后退 / 前进 1 帧 |
| `I` / `O` | 设为片段起点 / 终点 |

工具会在载入视频时自动探测帧率（也支持手动选择 23.976 / 24 / 25 / 30 / 50 / 60 fps）。

## 前置条件（只有一条，且大概率你已经满足）

**不需要安装任何软件或解码器**——播放与抽帧由浏览器原生完成。唯一要求是视频编码为浏览器支持的常见格式：

- ✅ **MP4（H.264）**、**WebM（VP9 / AV1）**、大多数 MOV —— 直接用
- ❌ HEVC / H.265、ProRes 等专业编码浏览器可能打不开 → 用 ffmpeg 一行转码：

```bash
ffmpeg -i input.mov -c:v libx264 -crf 18 output.mp4
```

### 关于剪辑功能的说明

- 剪辑使用 [ffmpeg.wasm](https://ffmpegwasm.netlify.app/) 在浏览器内运行 ffmpeg——**视频始终留在本机，不上传**。首次点击“输出片段”时需联网下载约 30MB 引擎（来自 jsdelivr CDN），之后浏览器会缓存，离线可用。
- 无损模式按**关键帧对齐**：起点会对齐到所选位置前方最近的关键帧，可能提前零点几秒到两秒（AI 生成的短视频关键帧很密，通常几乎无感）。若需要帧级精确且接受重编码，用下面的命令行方案。

## 命令行替代方案

习惯命令行或需要批量抽帧时，ffmpeg 一条命令同样无损：

```bash
# 抽一帧
ffmpeg -ss 00:01:23.456 -i input.mp4 -frames:v 1 frame.png

# 无损剪切一段（与工具行为一致）
ffmpeg -ss 00:01:23.456 -to 00:01:28.456 -i input.mp4 -c copy -avoid_negative_ts make_zero clip.mp4

# 帧级精确剪切（重编码，起点不偏移）
ffmpeg -ss 00:01:23.456 -to 00:01:28.456 -i input.mp4 -c:v libx264 -crf 18 -c:a aac clip_exact.mp4
```
